## #261's four owed corrections (D1–D4)

**Three attempts to state a positive safety property about the guard were each falsified.**
Stop attempting a fourth. **Delete the general claims and publish measured bounds only.**

1. **D1** — "whenever a catchable entry exists the total has already moved to a later bus" is
   false at any ETA age > 0. `planner.ts` does `boardable: canCatch(match) ? match :
   (catchable[0] ?? match)` — when nothing is catchable the fallback is `match` itself.
2. **D2** — the converse band's endpoints key off the **raw** eta, so the stated interval is
   displaced by the ETA's age: `(remaining+60, eta+150]` = 90 s + age, up to 132 m hidden.
3. **D3** — it is a **nothing-catchable** band, not a "single-live-entry" one. Width narrows
   to 60 s with three bunched buses.
4. **D4** — one quantity, two numbers: 90 s **wide**, 91 **inclusive integer seconds**.

Root cause of all four: the card tests the **raw poll-time** eta while the gate tests one
**counted down to now**. Any universal quantifying over configurations trips on that seam.

## Process facts worth keeping

- `POST /api/reports/{id}/update` **REPLACES** the note and **silently caps at 2000 chars**,
  returning `ok:true` either way. Carry prior text forward yourself; verify by **length** on
  read-back.
- `gh pr edit --body` **fails silently** here. Use `gh api -X PATCH` and verify by read-back.
- Select a workflow run by **name + headSha**, never by recency.
- **git can report a clean merge that is semantically broken** — two insertions on opposite
  sides of one anchor line became two declarations in one scope, with no conflict marker.
  Read the merged hunk; build.
- A recorded `--onto` base may be the branch's own copy of a **squashed** PR — which makes it
  the correct cutpoint and makes two of three "conflicts" phantom.
- `rider-sim` sequence stamps are **UTC**; the rest of this project is ET.
- This tree often sits on a long-lived branch behind master, so `git ls-files` finding nothing
  is **not** absence. Name the ref.
