## Problem and scoped change

Review15 demonstrated a held pinch spanning manual Done or natural ride expiry. On the next touch Leaflet's remaining document listener calls _resetView against a removed pane and throws. Both original cases fail on e7e9063 and pass on the preserved production98e535b bundle; those completed paired experiments remain intact under review-ux09-map/. This correction does not claim a blank-page failure.

Installed Leaflet1.9.4 TouchZoom.removeHooks removes only the initial container listener. An active gesture retains document touchmove/end/cancel handlers and a movement requestAnimationFrame. Its own _onTouchEnd also skips listener removal when no movement occurred. A local mapLifecycle.ts adapter cancels that map's gesture/frame and unregisters only its matching handlers before existing stop/remove. AllRoutesMap and RideRouteMap use it; live maps keep pinch, wheel, buttons and keyboard zoom. No synthetic global cancel, error suppression, dependency patch, touchZoom:false setting, or ETA change is introduced.

The adapter deliberately confines Leaflet1.9 internals to one small file because no public cancellation API exists. Its HTMLElement cast accounts for the installed type declarations rejecting document even though Leaflet itself registers these handlers on document. Future Leaflet upgrades must retain the browser regression. Other existing trip/berth map teardown paths were source-inspected only; their potential pre-existing held-pinch issues are outside this two-map review correction and are not claimed fixed.

Changed files: web/src/TransitMap.tsx (one import/two calls), new web/src/mapLifecycle.ts, new scripts/map-touch-teardown-check.mjs, all under services/shuttle-v2.
