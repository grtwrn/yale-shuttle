## Identity, causality and physical state

Each physical marker has its own episode for each vehicle/provider/route continuity segment. Its ID is the JSON tuple [schemaVersion,busName,providerId,routeId,segmentStartedAt,markerId,firstObservedNearAt]. All components exist on the opening poll; no global ordinals, final durations or future observations contribute. Version numbers advance only when an update is emitted. Every update's knownAt is its actual processing poll. Same-poll order is provider ID then marker ID; prefix deletion must preserve exact IDs, versions and update bytes.

The ledger receives raw observations and physical marker coordinates only. It never receives a detector anchor, phase, ETA, fitted value or eventual outcome. Enumerate all public physical markers independently of route order. Start an episode on an observed fix within75m. Track every subsequent fix through125m, retaining lastWithin75At separately. A fix beyond125m records a spatial exit interval [lastObservedWithin125At,firstObservedOutside125At]; it is not a service departure. Keep observations in the75–125m band explicit. One-fix approaches remain records.

Marker episodes never merge. Each update lists the IDs of other markers simultaneously within75m in that same poll. This is a contemporaneous relation only; no transitive closure, shared spatial identity, inherited alias set or whole-trip clustering is permitted.

Identity handling is independent of phase: exact duplicate provider observations deduplicate; contradictory same-poll provider observations fail. A provider handoff for a vehicle name, route reassignment or contention-state change censors its old marker episodes and starts a new continuity segment. Simultaneously contended names retain separate provider-specific tracks and an ambiguity flag. At the first later raw poll demonstrating a gap>60s, censor stale open episodes with that poll as knownAt and the last observation as the last physical evidence. Do not close at EOF or invent a departed-at time.

A censored episode remains in the evidence ledger. A later observation of the SAME provider and vehicle name beyond125m may append an absence witness, even if its route assignment changed. This bounds possible continued marker presence at that later instant; it does not fill the missing interval, undo censoring or erase the earlier encounter. A different provider is not such a witness. Censored episodes without a witness remain explicitly unresolved; possible persistence may conservatively create additional barriers. Report these separately rather than quietly expiring them.

Exact-coordinate plateaus are descriptive. A episode records its current plateau, largest observed near/band durations and the first knownAt at which a plateau inside75m lasts15s. This supports only `stationary_fix_supported`, never boarding. Changed coordinates support `possible_pass`; brief/open observations without either remain `uncertain`. Moving passes and short repeats remain potential pickups. No thresholds are tuned.
