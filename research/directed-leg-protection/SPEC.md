## Exact experimental rule, before replay

Implement a research-only network adapter around the unchanged production detector/departure reducer. Do not change server or web source. For each observation:

1. Require an existing state with the same provider ID and route, an uncontended vehicle name, a strictly newer poll and a gap at most60s (existing MAX_HANDOFF_GAP_MS). A provider handoff, route change, missing observation or unknown route disables this protection and retains baseline recovery.
2. Obtain the candidate that the unchanged detector would choose, including its150m global-versus-lookahead rule. Try a previously protected leg whose endpoints still contain the current anchor; otherwise try the current anchor's downstream leg. No arbitrary earlier/later leg scan is used to manufacture a match.
3. Use the exact directed runtime stop-leg slices: the usual tracer; if its legs bridge, use the existing no-skip legSlicesInOrder result only when it supplies every leg. Missing or bridged legs disable protection. No topology changes, nearest-line branch search or added stop occurrences.
4. Both previous and current fixes must project within75m of that same leg (existing AT_STOP_PIN_M). For a changed fix, raw displacement and forward distance along the slice must exceed8m (existing MOVED_M); both must be at most25m/s times the observed interval plus16m (existing MAX_HANDOFF_SPEED_MPS and two8m noise allowances). Backward or ambiguous projection disables protection. Segment-tangent heading alone is not a veto: a five-second fix may cross a corner. Repeated identical fixes may retain an already established protection certificate under the same continuity conditions, but cannot establish one.
5. If the ordinary candidate lies outside that leg's two endpoints, replace it by the closer endpoint and retain the leg certificate. Never choose the earlier endpoint if the detector has already advanced to the later endpoint. If the ordinary candidate is an endpoint, preserve the baseline selection and retain a still-supported certificate. When support fails, discard the certificate and use baseline behavior immediately.
6. The adapter supplies that anchor consistently to the detector's global and lookahead calls. It does not widen lookahead, accept a hop>5, recover a missing visit, extend a standing clock directly, alter departure logic or create a segment across a recovery. The existing22m/s training/outcome quality rule is untouched and remains separate from this narrow25m/s geometric admissibility bound inherited from detector identity recovery.

No tolerance sweep against arrival errors. These reused constants define the initial research arm. If focused fixtures expose an implementation error, record and fix it; a specification change is a new arm and must be recorded before running its aggregate comparison.
