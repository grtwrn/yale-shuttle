About Yale Shuttle Tracker

This app was built, and is still maintained, by the spouse of a Yale graduate student. It started with a familiar problem: she kept missing the shuttle because the official arrival times jumped around, and the only reliable way to catch one was to sit and watch the bus icon crawl across the map.

The person who built it also has ADHD, and working out where to go and which line to take was harder than it should have been. He wanted something that felt like Google Maps: type where you're going, get told when to leave and which bus to board. So he made one.

Some shuttles don't stop exactly where the published stop is. Where the data shows a consistent difference, the app shows both spots, so a first-time rider isn't left standing in the wrong place. Wherever you wait, give the driver a wave so they know to stop for you.

We'll keep working on making the times more accurate and the app easier to use. If something looks wrong, or you have an idea, use the 💬 Send feedback button in the app; it comes straight to us.

If you write code, the project is open source on GitHub: github.com/grtwrn/yale-shuttle. A review bot watches for pull requests around the clock, so contributions get a prompt response.

Yale Shuttle Tracker is an independent project. It is not affiliated with or endorsed by Yale University. Bus positions come from the public shuttle feed.
